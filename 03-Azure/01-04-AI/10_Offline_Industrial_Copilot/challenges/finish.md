## Congratulations

You finished the MicroHack *Offline Industrial Copilot*. You built, measured and disconnected a working agent yourself: a local model, local knowledge, local tools and a model trained in the cloud, running on the factory floor without a network.

Take these questions back to your own project:

* Which of your agent's tasks must work without a connection, and which can wait for one?
* How small can the model be before the tool calls stop being reliable?
* Where does your agent need a person to say yes?

## Where to go next

In this MicroHack you built every layer yourself on one device. If your customer runs Azure Local and wants a managed version of the same ideas (document ingestion, vector search, agents, an MCP server and a chat interface), read [Agentic Retrieval and Agents and Tools with Foundry Local](https://learn.microsoft.com/azure/azure-arc/agents-tools-foundry-local/overview). It runs on Azure Arc-enabled Kubernetes and is in preview. It is a cluster platform and not the on-device runtime used here, so check how the two relate before you compare them.

If you want to give feedback, please open an issue on the repository or get in touch with one of us directly.

Thank you for investing the time and see you next time!
