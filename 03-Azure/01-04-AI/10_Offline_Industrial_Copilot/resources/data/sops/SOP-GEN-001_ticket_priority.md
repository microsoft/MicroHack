# SOP-GEN-001 Maintenance tickets and priorities

- **Document:** SOP-GEN-001
- **Revision:** E (effective 2026-06-01)
- **Applies to:** all maintenance staff
- **Owner:** Maintenance Manager

## When to create a ticket

Create a ticket for every fault, every warning that is not fixed in the same shift, and every repair that needs a part or a specialist.

## Priority

| Priority | Meaning | First response | Target fix |
|----------|---------|----------------|------------|
| high | Safety risk, or the machine is stopped and production is blocked | within 1 hour | same day |
| medium | The machine runs but is degraded, or a warning limit is exceeded | within 8 hours | within 3 days |
| low | Cosmetic issue or planned work | within 5 days | next planned stop |

## A good ticket has

1. The machine ID (for example CNC-07).
2. A short summary of the symptom, and the error code if there is one.
3. The priority.
4. The measured values (for example vibration in mm/s) and the runtime hours.

## Escalation

If a high-priority ticket is not acknowledged within 1 hour, call the on-duty maintenance lead. The number is on the board in the maintenance office.
