# SOP-ROB-001 Welding robot torch and wire feed

- **Document:** SOP-ROB-001
- **Revision:** B (effective 2026-05-18)
- **Applies to:** welding robot ROB-04
- **Owner:** Maintenance Engineering
- **Related error code:** E-WLD-120 (wire feed fault)

## E-WLD-120: wire feed fault

1. Move the robot to the service position and complete SOP-SAF-001.
2. Check the wire spool. The wire must unroll freely with no tangles.
3. Check the feed rollers. Replace the rollers if the groove is worn.
4. Replace the liner if the wire is hard to pull through by hand.
5. Replace the contact tip. Use only tips of the same diameter as the wire (1.0 mm).

## Routine

- Replace the contact tip after every **8 hours of arc time**.
- Clean the nozzle at every shift change and apply anti-spatter spray.
- Check the tool centre point (TCP) once per month. If the deviation is larger than **0.5 mm**, run the TCP calibration and create a ticket.
