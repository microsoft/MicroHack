Now, the question I want you to keep for the rest of the day: which part of this is a rule, and which part is a judgement? [click]

Every one of these lines splits in two. Matching a reference, applying a tolerance of two pounds, spotting a duplicate: those are rules. The agent prepares it; a person decides.

That split is the whole design: the agent runs the rules, a person makes the judgements.

Before a process owner signs off, someone asks: what can it do, where can it go, can it be tricked, whose access does it use, and can we see what it did? Challenge six answers each with a control.

First, the harness tools: Web goes off. But Shell is still on, and a shell command can reach the network by itself, so that's not a boundary. This is: a guardrail with egress rules. One allow rule for the back office, deny everything else. And you start in Audit mode, where nothing is blocked, only logged.

We ran curl to Bing and to the back office. Both answered. Then in the trace, the decisions: Bing would be denied, the back office allowed, Foundry always allowed by a built-in rule.
